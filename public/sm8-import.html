ServiceM8 Import

Brings the jobs still open in ServiceM8 (status Work Order) across as Direct Jobs. Loading the list is a dry run: it only reads from ServiceM8 and saves nothing. Check each job, untick any you would rather finish in ServiceM8, then press Import. Jobs already brought across are skipped, so this can be run again on cutover day.

Review

All amounts are ex GST, like everywhere else in the app. ServiceM8's job total includes GST, so it has been divided by 1.1; the original figure is shown under each job. Invoiced to date is what ServiceM8 (or Xero) has already billed: the app only lets you invoice the rest, so get it right on part-billed jobs.
