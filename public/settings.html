Address autocomplete

Powers the site address lookup when building a quote, so addresses are picked from a verified list rather than typed freehand. Uses a Google Maps API key - safe to store here since these keys are restricted by domain in Google's console, not by secrecy.

Xero account mapping

Locks which Xero account code and tax type each category is allowed to post as, so a mismatched combination gets rejected before it reaches Xero rather than silently miscoded. Confirm these against your actual chart of accounts before pushing anything beyond the demo company.

Xero connection

Tracking category used to tag invoice lines and payroll timesheets back to a job. Create a Tracking Category called "Job" in Xero first (Settings > Advanced > Tracking Categories), then use the lookup below to get its real ID - Xero's own screens never show it, only the API does.

Numbering

Cost centre numbers (e.g. "7000-2") are worked out automatically from a job's number plus stage position - nothing to set there. These counters control what the next new quote, job, or invoice gets. Changing them doesn't renumber anything already created.

Quoting defaults

Used as the starting point on every new quote. Still adjustable per job.
