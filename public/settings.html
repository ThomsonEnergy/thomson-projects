Xero connection

Tracking category used to tag invoice lines and payroll timesheets back to a job. Create a Tracking Category called "Job" in Xero first (Settings > Advanced > Tracking Categories), then use the lookup below to get its real ID - Xero's own screens never show it, only the API does.

Numbering

Cost centre numbers (e.g. "7000-2") are worked out automatically from a job's number plus stage position - nothing to set there. These counters control what the next new quote, job, invoice, or purchase order gets. Changing them doesn't renumber anything already created.

Quoting defaults

Used as the starting point on every new quote. Still adjustable per job.

Rate tiers

Sell rates only - what's charged to clients for labour. Used when "Labour" is picked as a quote line item. Each employee's own cost rate is set on their profile under Users & Roles, since actual wages don't map cleanly to these tiers.

Integration keys

Stored in the database rather than baked into the code, so a key can be rotated here without a redeploy. Supabase's own URL and service role key can't live here - the app needs those just to reach this database, so they stay as Netlify environment variables. These fields are write-only - once saved, the actual value never gets sent back to the browser, just a status showing whether something's set. Leave a field blank to keep whatever's already saved; type a new value to replace it.

Test Formbay connection
