# Site security and bug review (23 Oct 2026)

Read-only review of the whole app after the 19 to 23 Oct updates (69 commits, 183 code files, 24 migrations): every Netlify function, every migration since 19 Oct, the live RLS, grants, views and storage snapshot, every page, the Supabase advisors and `npm audit`. Done as a 114-agent sweep (36 reviewers by area, two independent checks on every finding, then a write-up): 195 findings passed both checks, 24 passed one (section P), 9 were refuted, 58 duplicates merged. Nothing was changed. Rows are grouped by root cause and ordered worst first (critical, high, medium, low). **(checked)** marks items reproduced by running code or confirmed against the live database; **(checked on production)** marks items the orchestrator confirmed by querying production on 23 Oct. Fix status is tracked in `docs/DECISIONS.md`: delivery 1 (database lockdown, migration 20261124131544, PR 213) went live 24 Oct 2026; deliveries 2 and 3 (functions, money, payroll, leave balances, pages, migration 20261124150000, PR 214) cover the rest, with the few rows left out listed under backlog item 15. Previous review: `docs/BUG_REVIEW.md` (19 Oct).

Two extra facts: `npm audit` shows 9 high findings, all in dependencies with no safe fix short of a major upgrade (xlsx prototype pollution and ReDoS, no fix on npm; pdfjs-dist arbitrary JavaScript on a malicious PDF, fix is the 6.x major; puppeteer-core chain via extract-zip and proxy-agent, fix is the 25.x major); and the live table `notifications_tidy_20261023` has RLS off (S5).
